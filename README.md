# Genspark OS Concept

Stage: planning only. This repository contains a proposed Linux distribution, not a built operating system.

The [preserved concept and remaining milestones](docs/concepts/linux-distribution.md) now live under docs/concepts/.

Related projects: [Vitruvian fork](https://github.com/HenricHuntsman/Vitruvian) for experimental OS source; [AgentFoundry Workspace](https://github.com/HenricHuntsman/AgentFoundry-instantly) for a separate application. Their code and maturity are independent.

No ISO, installer or successful boot is established here. Repository slug and Git history are preserved.
